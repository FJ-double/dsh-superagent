# 内容生产工作台 · 项目开发方案总览 v0.5

> 汇总时点：2026-11-02 15:35。本文把 14:40 以来的全部答复收敛成一份可读的整体方案，取代此前分散的多份补丁（v0.3 任务书 + v0.4 对齐稿 + v0.5 变更 + 扇出规格 + 卡片规格 + 台账），作为当前唯一口径。
> 不含任何生产代码。本文只定义：范围、架构、契约、闸门、质量、成本、节点、风险。

## 一、做什么 / 不做什么

### 1.1 做
**一个话题进来 → 三个平台出去**：未来不一定只有三个平台，可以留接口预备以后接入其他平台。
| 平台 | 形态 | 规格 |
|---|---|---|
| 公众号 | 长文 | 1500–3000 字 + 6–10 图 |
| 小红书 | 卡片组 | 6–12 张 1080×1440 + 正文 ≤1000 字 + 标题 ≤20 字 |
| 抖音 | 竖屏视频 | 60–90 秒，9:16，真分镜 + 配音 + 动效 |

一条完整的链：**选题 → 你批 → 取证 → 成稿 → 你批 → 版式渲染 → 质检 → 你批 → 三平台发布 → 回读核实 → 数据回采**。全程你只点三次（每道闸门），其余我兜。

### 1.2 不做（明确划掉，避免后期扯皮）
- 数字人、声纹克隆（契约留字段，不实现）
- 多语言本地化
- 通用编辑器替代品（**不改稿、不精修**，你只做闸门决策）
- 外部信号监听（热点榜、下拉词、竞品监控、评论挖需求）——**归另一套系统**，本工作台不重复建设
- 自动定时立项（见 §2.2）

## 二、输入从哪来、谁来定题

### 2.1 唯一的料源：Obsidian 仓库
- 部署：虚拟局域网内一台设备，装 Obsidian **Local REST API** 插件，开端口
- 访问：只读凭据，不出公网，本地 sqlite 增量索引（按文件哈希，不整库重扫）
- 素材入库存一张**三格小卡**：`出处` / `授权` / `标签`，10 秒填完
- **硬规矩**：`出处`与`授权`禁止由模型自动补（模型会编一个看起来很像的链接，等于给自证盖假章）。没写出处的素材可当灵感与观点用，**不得进正文的事实断言**
- 参考视频**不进成片**：只抽参数（钩子/节奏/结构/动效）落成风格模板，供版式与渲染读

### 2.2 选题权归你，三个入口，没有第四个
1. **你给题** → 直接开工
2. **你给个模糊想法** → 我先问清关键点（用户画像、内容匹配等），**问清楚之后**再出候选
3. **你要推荐** → 走推荐引擎，出 3–8 个候选、预勾选 1–3 个、你批红

**初版不主动立项、不定时出题**。仓库里料再多也不会自己开跑。事件层退化为索引层（新素材入库只建索引，不触发动作）。**主动推荐/自主立项放在以后版本实现**——所以这条不是永久否决，是排期靠后。

### 2.3 推荐引擎：三只脚同时站住才推
| 脚 | 内容 |
|---|---|
| 已发内容台账 | 近 90 天发过什么，避免重复，或做续集/反差 |
| 数据表现 | 哪类角度真有效（完读/收藏/涨粉）；数据不足就明写"数据不足"并降权，不假装有依据 |
| 仓库素材可用性 | 必须能点名"用哪几条素材支撑" |

硬规则：**点不出具体料的候选不许出**；料不够就直说"现在只能撑起 X 个方向，建议先补料"，不硬凑。

## 三、架构

### 3.1 分层（L0–L7，此处保留内部编号但附白话）
| 层 | 白话 | 产出 |
|---|---|---|
| L0 | 资产与底座（风格、钩子库、素材台账、模型网关、编排） | 配置与库 |
| L1 | 出题 | 候选集 |
| L2 | 找证据 | 事实清单（唯一口径） |
| L3 | 写稿 | 母版叙事 + 三形态文案 |
| L4 | 排版/分镜 | 长文 HTML / 卡片版式 / 分镜表 |
| L5 | 渲染 | 长图、PNG、成片 |
| L6 | 质检 | 质检报告 |
| L7 | 发布与回采 | 发布包 + 数据 |

### 3.2 一次研究、中段扇出（多平台的核心形状）
```
你给题 → 出题(一次) → ✋批 → 取证(一次，事实版本锁定)
                                   │
        ┌──────────────── 扇出 ────────────────┐
     公众号长文            小红书卡片组          抖音竖屏视频
        └──── 各自：文稿✋ → 版式渲染 → 质检 → 发布✋ → 回读 → 回采 ────┘
```
- 共享：选题、取证、事实清单、**母版叙事**
- 分叉：文体、版式渲染、平台规则质检、发布适配
- **母版形态**先定（视频优先为常态），子形态只能删减、不得新增论点

### 3.3 一致性三条硬规则
1. 三条产物引用**同一份事实清单版本**；改事实要升版本并触发其他平台"漂移复核"
2. 论点只有一份，母版定，子形态不得加
3. 发布卡上直接显示"三平台关键数字一致性 ✅/⚠️"；价格统一取整口径

### 3.4 失败隔离
一个平台挂了不连坐：各自独立状态、独立预算、独立重试；父状态只报"部分完成"；重跑能细到"只重跑抖音分镜"，不重跑取证；已发布的不受重跑影响。

## 四、你看到的东西：闸门卡片

三道闸门（选题 / 文稿 / 发布），每道一张**票拟式卡**：
- **九个字段**：一句话请示（≤30 字）｜我的建议＋置信度｜为什么（≤3 条带数字）｜关键数字（质量分/溯源率/成本/限额余量）｜最坏情况＋我为什么不担心｜已做/未做｜最多 2 个备选｜唯一一个请示问题｜页脚（版本/有效期/今日第几张）
- **三个按钮**：同意（零输入）｜拒绝（零输入，默认勾"记入长期偏好"）｜自定义回复（打字，**先回执"我理解你要 X，对吗"确认后才执行**；解析不了就回问，绝不猜）
- **不合并**：每平台各自一张文稿卡 + 一张发布卡（一题 6 张）。视频卡永远单独且最先批（最贵）
- 减噪只靠三件：卡变短、到达时间错开、可选"其余平台按同一母版放行"的临时授权勾
- 自检：**卡片上没有"我的建议"= 我做错了**

## 五、我什么时候停下来找你

**必问九类**：花钱（超上限/开新额度）｜对外发（含回复读者）｜改方向（赛道/定位/体裁配比）｜动数据账号权限｜高风险题材（医疗、理财、教育升学承诺、法律、政企负面）｜有事实缺口或来源打架｜我没把握｜同一件事第二次失败｜**我没见过的情况（不问就是猜）**

**不问**：常规返工（换图/改排版/统一术语/补图表）、按既定原则的常规执行

**你定过的事不再问第二遍**，但必须：① 先贴出你的原话与日期 ② 赛道/体裁/预算/风险级四项未变 ③ 同一类事项。**花钱、对外发、高风险、改方向、动账号权限永远重问**

**你不设注意力上限**（项目刚起步，先要信息对称）。审计留全量，每周出一页"我本可自己判断"的复盘，用数据决定以后少问哪类。

## 六、质量与合规

### 6.1 质检两层
| 层 | 项 | 是否拦发布 |
|---|---|---|
| 硬错层 | 事实校验、合规（AI 标识/授权/平台限额）、结构完整、**音画同步**（视频分支） | **拦** |
| 风格层 | 去陈词、AI 味、套话密度 | **不拦**，只进质量分与日报 |

审查角色硬约束：只读、不改稿、不联网、不拿发布凭据；同一稿最多三轮，三轮不过弃稿。

### 6.2 事实链条
- 每条断言挂 `source_id + 位置`；来源分级 S1 官方/S2 权威媒体/S3 行业媒体/S4 自媒体；正文断言只许 S1–S3
- **判定对象是笔记里的原始出处，不是笔记本身**（否则等于自证）
- 找不到证据的点进"必须回避"清单；来源打架进冲突清单并弹卡问你

### 6.3 合规（延续既有决定）
- AI 生成标识：走**平台发布声明的开关**，每次必须主动声明；导出链路**禁止剥离元数据**
- 出处标注：对外默认不标（`minimal`），但内部溯源不放松；**逐字引用他人文字/图表强制标注**
- 热门案例：只作参考，不进成稿像素、不二次分发

## 七、成本

| 项 | 量级 |
|---|---|
| 公众号长文 | 1×（约 ¥3–5/篇） |
| 小红书卡片组 | 约 1.2×（约 ¥2–4/组） |
| 抖音竖屏视频 | **8–20×**（约 ¥15–35/条） |

## 九、风险（按严重度排序）

| # | 风险 | 为什么严重 | 应对 |
|---|---|---|---|
| 1 | **首期就上视频＝把最难的一层放进第一步** | 你最初的三大不满之一就是"视频只有图片切换"；渲染/动效/音画对齐是最容易翻车的地方 | N4 样片风险闸，不过关不铺并发 |
| 2 | 抖音发布无 API | 个人号大概率无法自动发布，工期承诺会落空 | N1 核实；若无则走打包一键发（与小红书同路） |
| 3 | 仓库无元数据 → 素材可用性索引弱 | 推荐准确率打折，容易出现"推了但没料" | 新素材三格小卡从现在积累；推荐时逐条列依据；一个月后看覆盖图 |
| 4 | 三平台一致性问题 | 数字口径打架比单篇错误更伤信任 | 事实版本锁定＋发布卡一致性校验 |
| 5 | 视频成本失控 | 单条 8–20×，两条就超预算 | 扇出前预估上卡，子预算独立熔断 |
| 6 | 卡片数量（一题 6 张） | 一天两题 12 张，可能反过来消耗注意力 | 卡变短、错开到达、可选临时授权；若真吵，回来说一句就改合并 |

## 十、还没定的（等你一句话）

1. **N4 样片风险闸是否同意**（我建议同意）
2. **`inbox/系统复盘/` 允许我写回仓库吗**（唯一回写口，用来沉淀复盘结论；不想要就不开）
3. **三平台同日发还是错峰发**（默认同日，`staggered` 排期队列预留）
4. **存量笔记元数据是否清理**（默认不动，一个月后看覆盖图再定）
