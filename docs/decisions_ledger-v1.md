## 2. 安全栏（D20 的三道闸，任一不满足就重新问）

Agent 想引用台账跳过提问，必须同时满足：
1. **回显**：把原话与日期贴出来（"你 11-02 说过『xxx』"），让你能当场纠正；
2. **条件未变**：赛道/体裁/预算档/风险等级四项都没变（变了就是新问题）；
3. **同类**：是同一类事项，不是"看起来像"。

**永不复用、每次必问**：花钱、对外发（含回复读者）、R2 及以上风险、改方向、动数据/账号/权限。

## 3. 本轮被撤回/推翻的旧设想（连同理由留档，避免以后又绕回来）

| 撤回的东西 | 原设想 | 为什么撤回 |
|---|---|---|
| 每日人工卡上限（≤6 张/天） | 保护注意力 | 项目刚起步，先要信息对称，不要节省；改为"必问/不问"清单 |
| webhook 事件中台 | 抄文章的自动化中台 | 事件源（网络信号）已划给另一套系统；留给我们的只有仓库变更与定时，中台成本大于收益 |
| 机器自动补全出处 | 让 Agent 读正文推 origin | 会编造链接，污染事实溯源，比缺来源更危险 |
| 「每日扫仓库、材料够就出选题卡」 | 无人在场也能开工 | **越权**：替你决定今天做不做、做什么。改为不主动立项，选题权归你（D25） |
| 「先用 A（AI 工具实测）当主赛道」 | 便于收敛 | AI 是大类不是窄赛道；固定方向会窄化选题。改为软先验、可为空 |
