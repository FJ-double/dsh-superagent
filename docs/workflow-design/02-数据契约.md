# 02 数据契约与中间产物（JSON Schema 设计）

> 本文件定义全链路**所有中间产物的结构**。这是全套设计里最需要先冻结的部分：
> 数据结构定了，各层可以并行开发、可以换模型、可以换渲染器、可以单独重跑。
> 正式实现时这些将落地为 `schemas/*.schema.json`（JSON Schema 2020-12）+ 生成的语言绑定；
> 本文档给出字段、类型、约束与语义，评审通过即冻结 v1。

---

## 0. 通用约定

### 0.1 统一信封 `StageResult`

每个阶段的产物都包在信封里，便于调度、缓存、审计：

```jsonc
{
  "envelope_version": "1.0",
  "artifact_id": "art_01J9Z8K3QW",
  "run_id": "run_20261101_0007",
  "ticket_id": "40b00492bfa306992ec189916d9746fe",
  "stage": "L3.script",
  "schema": "script@1.2",
  "created_at": "2026-11-01T12:40:00Z",
  "inputs_hash": "sha256:9f2c…",          // 归一化输入的哈希，缓存键的一部分
  "upstream": ["art_01J9Z8K3AB", "art_01J9Z8K3CD"],
  "producer": {
    "kind": "llm|tool|human",
    "model": "creator-large-2026-09",
    "prompt_id": "l3.section_expand@4",
    "params": {"temperature": 0.7, "seed": 42},
    "gateway_call_ids": ["gw_01J9…"]
  },
  "cost": {"usd": 0.031, "tokens_in": 8120, "tokens_out": 2210, "render_sec": 0},
  "cache": {"hit": false, "key": "sha256:7a1b…"},
  "payload": { }
}
```

### 0.2 命名与 ID
- 前缀：`run_` / `art_` / `stg_` / `idea_` / `clm_` / `sh_` / `pk_` / `qa_`。
- 时间一律 UTC ISO-8601；时长单位 **秒（浮点）**；金额单位 **USD**（展示层换算人民币）。
- 枚举值一旦发布只能新增不能改名（改名走 schema 大版本）。

### 0.3 哈希与缓存键（必须全局一致，否则缓存失效）
```
canonical(x) = JSON.stringify(sort_keys(x)) 去掉空值字段、浮点保留 3 位
cache_key    = sha256( canonical(inputs) + "|" + schema_version + "|" + producer_version )
shot_key     = sha256( canonical(shot_json) + "|" + assets_version + "|" + style_version + "|" + renderer_version )
```

### 0.4 版本与迁移
- 每个 schema 有 `MAJOR.MINOR`；**MINOR 只能加可选字段**，MAJOR 变更需 ADR + 迁移脚本。
- 产物里写 `schema` 字段；读取方按版本分支处理，禁止"猜"。
- 历史产物**永不覆盖**（内容寻址 + 只追加）。

### 0.5 存储布局（对象存储）
```
s3://content-prod/runs/<run_id>/<stage>/<artifact_id>.json
s3://content-prod/runs/<run_id>/media/<shot_id>/<attempt>/<file>
s3://content-prod/assets/{style,music,broll,fonts,templates}/<version>/…
s3://content-prod/publish/<publish_id>/…
```

## 14. 校验策略（实现层规范）

1. **入口校验**：每次阶段输出先过 JSON Schema；失败 → 带着校验错误回给模型修复（最多 2 次），再失败 → 阶段失败并告警。
2. **语义校验**（schema 之外，必须单独实现）：
   - `claim_ids` 必须都能在 `fact_sheet` 中找到；
   - `assertable=false` 的 claim 出现在正文断言位 → fail；
   - `shot.start` 连续、无重叠、无空洞，总长 == `audio_plan.total_dur` ±80ms；
   - `words_ts` 单调递增且与 `dur` 匹配；
   - `assets` 全部在 `asset_manifest` 中有版权字段；
   - 所有枚举外值视为错误（禁止自由文本代替枚举）。
3. **不可变**：产物只追加；修正即新 `artifact_id`，`upstream` 指向旧版。
4. **可 diff**：任意两个同 schema 产物可结构化 diff，用于"改了什么"的审计与回流定位。
