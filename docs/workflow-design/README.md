## 一页结论

1. 三个症状都是**架构缺层**，不是提示词问题：缺发散层、缺研究取证层、缺分镜与组件化渲染层。
2. 主干是 **L0 资产 → L1 选题 → L2 取证 → L3 脚本 → L4 分镜 → L5 渲染 → L6 质检 → L7 分发反馈**，
   三道闸门（选题/脚本/发布）+ 三道结构化原则（JSON 中间产物、机器可判定闸门、幂等与分镜级缓存）。
3. 图文与视频共用 L0–L3，在 L4 分支：视频走带图层的时间线 + Remotion 组件渲染，图文走模板排版渲染。
4. 落地顺序：**先图文验证内容质量假设，再做视频消除幻灯片感，最后无人值守**，顺序不可颠倒。
5. 本套文档不含代码；确认 00 第 11 节的 10 个问题后即可进入 P1 开发。
