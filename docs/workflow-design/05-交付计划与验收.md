# 05 交付计划、验收标准与风险跟踪

> 原则：**不要一次做完**。先用最便宜的形态验证"内容质量能靠架构提上来"，再投渲染工程。
> 顺序反了，会陷在"做特效"里出不来，而内容依旧平庸。

## 3. P1 图文先行：任务拆解

| 编号 | 任务 | 产出 | 验收 |
|---|---|---|---|
| P1-1 | 建 L0 最小资产包 | 选题矩阵（枚举 + 初始权重）、钩子库 ≥100 条、事实源清单 20 条、style token v1、图库/字体 | 资源可被流水线读取且带版本 |
| P1-2 | 模型网关 + 编排骨架 | 统一能力接口、路由表、重试/降级、成本记账、状态机（created→scripted） | 一个 run 可从 created 跑到 scripted 并可重入 |
| P1-3 | L1 选题 | 三路发散 + 评分 + 聚类去重 + 历史查重 | `eval_ideas` 达标；批量出 40 候选 ≤ 3 分钟 |
| P1-4 | L2 研究取证 | 检索计划、抓取、抽取、交叉校验、fact sheet | `eval_facts` 幻觉判出 ≥95%；来源独立数 ≥3 |
| P1-5 | L3 脚本 | 大纲 + 逐节扩写 + critic + 密度校验 | 金标对比：密度 ≥90%，结构分 ≥4/5 |
| P1-6 | 图文排版渲染 | HTML 模板 6 套 + 无头浏览器出图/长图 + 封面 3 选 1 | 输出符合平台尺寸；字体/对比度检查通过 |
| P1-7 | 文本 QA + 闸门 | 组 1/2/3 检查 + 飞书审批卡片 + 发布包生成 | 每次发布有 qa_report；闸门点击可用 |
| P1-8 | 冷启动跑批 | 连续 5 天 × 3 篇，人工只做闸门 | FPR ≥60%，人工 ≤5min/篇 |

**P1 的关键验证问题**：*把"一次生成"拆成"发散 + 取证 + 分节写作 + 评审"之后，内容是否真的变厚、变新？*
如果没有明显变化，**不要进入 P2**——先查 L2 是否真在检索、L3 约束是否真在生效。

## 4. P2 短视频：任务拆解

| 编号 | 任务 | 产出 | 验收 |
|---|---|---|---|
| P2-1 | 分镜规范与生成 | `shot_list` 生成 + 时长由 TTS 反推 + 节奏规则静态校验 | 每条成片 shot_list 通过反幻灯片静态检查 |
| P2-2 | Remotion 组件库 | 10 个组件：背景/标题/卡拉OK字幕/数字/图表/引述/对比/步骤/转场/结尾 CTA | 组件参数化，改参数不改代码 |
| P2-3 | TTS 与音频 | 词级时间戳、BGM 选库与 ducking、响度归一、SFX 卡点 | 音画偏差 ≤80ms；-14 LUFS ±1 |
| P2-4 | 渲染与缓存 | 镜头级缓存、并发渲染、成本/时长护栏、降级策略 | 单镜头改动仅重渲该镜头；两次渲染哈希一致 |
| P2-5 | 视频 QA | 组 4/5 检查（黑帧/静音/字幕/静态连续/事件密度） | `eval_qa` 召回 ≥95%，误报 ≤5% |
| P2-6 | 30 条成片验证 | 真实选题批量出片 | 全部指标达标；人工抽检 ≥3 分率 ≥70% |

**P2 的关键验证问题**：*程序化组件 + 音频驱动的时间线，能不能彻底消灭"图片切换感"？*
量化答案就是组 5 的四个指标（静态连续、事件密度、运动层数、镜头数/分钟）。

## 6. P4 复利方向（按 ROI 排序）

1. **跨形态复用**：一次研究 → 长文 + 卡片 + 短视频 + 长视频（单位研究成本 ÷3）；
2. **生成式片段精修**：角色/场景一致性（参考图 + LoRA/固定 seed + 后处理 LUT）；
3. **A/B 规模化**：标题×封面×开场 3 秒的组合实验，bandit 自动收敛；
4. **换模自动化**：评测集驱动的模型替换（成本降 30% 而不掉质量）；
5. **风格资产化**：多栏目/多账号风格 token 与模板库，复制产线。

## 7. 验收清单（可直接用于每个阶段的评审会）

**架构**
- [ ] 每个阶段有明确输入/输出 schema 且已版本化
- [ ] 任一阶段可单独重跑，不影响其他阶段产物
- [ ] 业务代码不直连模型厂商
- [ ] 同一输入两次运行产物一致（模型温度 0 或固定 seed）

**质量**
- [ ] 发布前 100% 有 `qa_report` 且 decision=pass
- [ ] 断言 100% 可溯源；无源断言 0
- [ ] critical 项 fail 绝不放行
- [ ] 抽检记录与发布记录一一对应

**成本与效率**
- [ ] 单条成本在预算内（P95 不超 1.5× 均值）
- [ ] 缓存命中率 ≥ 50%（P2 后镜头级）
- [ ] 人工 ≤5 min/条
- [ ] 端到端 P95 时长符合 SLO

**合规**
- [ ] AI 生成标识存在
- [ ] 素材版权字段完整、无过期
- [ ] 敏感行业断言有白名单来源或已删除
- [ ] 发布账号最小权限 + 熔断开关可用
