# 部署到 HP（三选一）

先说实话：我跑在一个容器里，看不到你那台 HP，也没有它的 SSH，所以**第一步得你在 HP 上执行**。
下面三条路按"你机器上有什么"挑一条，都在 5 分钟内能通。

---

## 路线 A：HP 上有 Docker（最省事）

```bash
# 在 HP 上
git clone -b agent/extract-article-design-903b08e5cb03 https://github.com/FJ-double/dsh-superagent.git wb
cd wb/deploy
cp ../config.example.toml ./config.toml      # 然后填 [vault.*] 与 [webui]
echo "WB_WEB_TOKEN=$(python3 -c 'import secrets;print(secrets.token_urlsafe(18))')" > .env
docker compose up -d
docker compose logs -f        # 看到"工作台 WebUI 已启动"就是好了
```

## 路线 B：HP 上是 Linux（无 Docker）

```bash
# 在 HP 上
git clone -b agent/extract-article-design-903b08e5cb03 https://github.com/FJ-double/dsh-superagent.git wb
cd wb
sudo TARGET=/opt/workbench ./deploy/install.sh
```

脚本会：检查 python3.11+ → 建 `workbench` 系统用户 → 拷代码到 `/opt/workbench` →
生成 `config.toml`（若不存在）→ **随机生成页面口令写到 `/etc/workbench.env`** →
装成 systemd 服务并自启。跑完它会直接把口令和访问地址打给你。

日常运维：

```bash
sudo systemctl status workbench
journalctl -u workbench -f
sudo systemctl restart workbench
```

## 路线 C：HP 上是 Windows，或你只想先试试

```powershell
git clone -b agent/extract-article-design-903b08e5cb03 https://github.com/FJ-double/dsh-superagent.git wb
cd wb
copy config.example.toml config.toml
$env:WB_WEB_TOKEN="你自己定的口令"
py -3 -m workbench.cli serve --host 0.0.0.0 --port 8787
```

长期跑就把它做成"任务计划程序 → 开机启动"，或在 WSL 里走路线 B。

## 填配置时注意三件事

1. **`[webui] token` 一定要填**：绑 `0.0.0.0` 但没口令，服务会**直接拒绝启动**——闸门卡上有"同意发布"，内网裸奔等于谁都能替你拍板。
2. **Obsidian 如果就在 HP 上**，取材可以走本机，最安全也最快：
   ```toml
   [vault.readonly]
   driver = "http_rest"
   base_url = "http://127.0.0.1:27124"   # Local REST API 插件端口
   token = "插件里生成的只读 token"
   ```
   复盘库直接用本机目录：
   ```toml
   [vault.review]
   driver = "fs"
   root = "/srv/obsidian/复盘库"          # 换成你的真实路径
   ```
   注意 systemd 单元里 `ProtectHome=read-only`，如果复盘库放在 `/home` 下，需要把
   `ReadWritePaths=` 那一行的注释打开并指向真实路径。
3. **防火墙**：`sudo ufw allow from 192.168.0.0/16 to any port 8787` 只放行内网，别暴露到公网。

## 验证清单（每条都能自己确认）

| 检查 | 命令 | 通过的样子 |
|---|---|---|
| 服务活着 | `curl -s -o /dev/null -w "%{http_code}" http://127.0.0.1:8787/` | `200` |
| 接口要口令 | 同上但访问 `/api/status` 不带口令 | `401` |
| 看图 | 浏览器打开 `http://<HP的IP>:8787/` | 顶部五个能力色块 + "现在缺什么" |
| 能跑 | 页面里写个题目点"开跑" | 出现 G1 卡片与三个分支状态 |
| 数据落地 | `ls .data/artifacts .data/cards` | 有产物与卡片 JSON |

## 出问题怎么找我

把这三样发我，我基本能定位：
1. `journalctl -u workbench -n 50`（Docker 则 `docker compose logs --tail=50`）；
2. 页面上"现在缺什么"那一栏的截图；
3. `config.toml` 里**去掉 token/密码之后**的内容。
